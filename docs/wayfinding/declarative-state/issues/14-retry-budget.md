## Question

首版几何目标推进预算是含首次共3次，还是首次加3次纠正（共4次）？被动观察采用哪些可调检查点？最终目标语义提交与内部动画帧的区别以迁移票为准，不按底层position/size调用各扣一次。

## Votes

- execution_domain：总计3次，含首次；观察间隔不宜未经证据锁死。
- execution_platform：总计3次，含首次；提交后250ms/1s/5s三个相对观察检查点。
- execution_testing：首次加3次纠正，共4次；次数只是可调工程默认。

## Answer

用户在逐项解释后明确同意：同一目标的一轮几何调整包括第一次在内，总共最多3次尝试。此为用户裁决，不是2:1多数票自动采用。

用户随后单独确认被动检查节奏：发出调整后250ms、1s、5s作为可调默认检查点。这些是相对时间，不是依次再等250ms、1s、5s；是读取结果的检查点，不是三个强制写入或重试时间点。

一旦有效读回或系统事件确认目标已实现，取消后续专门检查。到5s仍未确认则停止本轮目标专用检查，保留意图和原因，继续接收正常系统事件；到期不证明永久不支持。检查仍须核验当前对象与目标版本，旧轮次不能确认新目标或补充重试预算。后续可根据实际表现调优参数。

失败后保留原始意图和阻塞原因；相关条件实质变化或新的有效意图才重新评估，不每隔数秒无限补充次数；已确认不支持或出现未知竞争时不为凑满次数继续写。

参数只针对几何目标推进，不逐帧计正常动画，也不自动适用于焦点或非幂等Space操作。用户已单独确认动画中途失败也占用一次，见 [动画在终点前失败如何计入尝试预算](19-animation-budget.md)。次数与检查时间分别获得用户确认，历史专家分歧保留在Votes中。
