# 外部几何接纳采用哪种稳定采样默认值

## Question

稳定采样使用现有150ms静默加结束后新鲜读回，还是至少3次快照跨200ms？如何界定首版默认与后续测量调优？

## Votes

- evidence_domain：推荐3次独立快照跨200ms；临时约束两次相关尝试和5s缓存，但非永久事实证据。
- evidence_platform：推荐150ms静默加新鲜读回；固定3次缺少充分依据，样本数不能替代证据政策。
- evidence_interaction：未选择固定数字，要求新鲜读回、版本检查和有界成本。

## Answer

用户确认150ms静默后新鲜读回，并明确补充防抖：“如果有新的事件到达，推迟计算。”此项为用户裁决，不是专家一致通过。

- 按窗口实例合并相关移动/缩放事件，保留最新候选。新的有效相关事件到达时，取消旧的待执行计算并将截止时间推迟到该事件之后150ms；不为每条事件积累一项待执行任务。
- 无关窗口/领域事件不推迟该窗口计算；已识别过时事件或自身回声沿证据政策处理，不能用于覆盖意图或刷新重试预算。
- 交互仍在进行时继续等待。交互结束且相关事件安静满150ms后，重新读取最终几何，核验身份、当前意图版本和接纳资格，再计算并提交对应布局转移。
- 等待期间发生新事件使旧候选失效；读回或计算期间的新版本也必须在提交门禁中拦截。连续事件可持续推迟这次外部布局接纳，不冻结独立的原生观测、其他窗口或明确命令。
- 150ms是可调防抖默认，不是用户来源、永久稳定或尺寸能力证明；无需强制3次/200ms采样。重试与能力证据仍遵守各自决策，防抖不补充写入预算。

## Acceptance

在0ms、100ms、200ms到达同一窗口的有效几何事件，不能在150ms或250ms提交旧候选；至少等到350ms且交互结束后新鲜读回，再提交最终结果。无关窗口事件不推迟该期限；期间新命令不能被旧候选覆盖；连续事件不积累多个计算任务。
