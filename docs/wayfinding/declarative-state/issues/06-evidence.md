## Question

如何区分关联写入回声、稳定外部变化、未知变化和尺寸约束？何种证据足以接纳、暂停或重新验证，怎样在无法证明操作者身份时避免失去意图或永久僵持？

## Answer

几何和能力证据规则三方支持，按用户授权采用。数值门槛与未知焦点让权拆票，不计入本票共识。

- 回声关联检查实例、效果领域、意图版本、尝试记录和目标；相同几何或相近时间不证明来源。旧回声不能改变新意图或直接完成新版。
- 明确交互关联到对象，期间暂停竞争写入；结束后新鲜读回、核验身份和当前版本，再映射为领域布局编辑。旧手势不能覆盖期间的新命令。
- 无手势证据的稳定外部几何，只有此前目标已实现、无未满足或受限待恢复意图、无写入/动画/转换关联时，才按政策接纳为“外部调整”。这不是证明用户操作。领域映射歧义则保持冲突。
- 未满足意图与未知变化冲突时保留意图、差异和证据缺口，暂停竞争写入；有限无副作用重验后可保持静止blocked。
- 明确能力只能按所获证据精度建约束；size settable不提供具体最小宽度。预算内相关尝试反复得到替代结果至多形成当前目标/上下文的临时执行限制，不证明永久最小值。
- 约束绑定incarnation与相关上下文；身份换代丢弃，相关模式/拓扑变化使适用性待重验，新意图重算但不无差别删除可信事实。
- 不主动聚焦、切Space或改变其他布局取证；探测仅使用已授权效果尝试。过期只使证据失效，不自动重开无限写入。
- 采样候选提交时再校验当前意图版本；新意图/新手势/转换使候选失效。实际焦点由有效原生观测更新，是否终止冲突激活意图另票决策。

### 验收

800受限实现为1000不会静默改成1000意图；正常完成800后稳定外部调整900可接纳；采样900期间新命令700不被覆盖；同ID新实例不继承旧约束；不为取证切Space。
