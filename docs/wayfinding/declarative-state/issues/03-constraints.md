# 能力约束下如何保留意图与派生有效目标

## Question

请求宽度 800、确认当前最小宽度 1000 时，意图如何处理？

## Answer

三位专家一致，用户明确确认：保留 800 的原始意图，按可信约束派生 1000 的有效目标；达到后标记受限实现，不反复写 800。用户再设 900 后，约束解除且条件允许时实现最新 900。

有效目标是派生值，不是第二个意图源，不要求所有领域机械复制状态。一次失败或读回不足以证明永久约束。无安全替代或证据不足则保留意图及阻塞原因。焦点/Space 目标不能任意换对象作为完成。解除约束需重新验证，并避开正在进行的交互。

## Resolution basis

用户在当前建图讨论中明确确认；详见原任务上下文。相关专家票的共同意见已在 Answer 中标明，范围票包含用户后续修正。
