# 稳定竞争成立前是否允许焦点重试

## Question

尚未确认稳定外部焦点竞争，首次激活遭遇明确暂时失败且出现新的正向可执行证据时，允许一次额外激活尝试，还是本次显式请求仅提交一次？

## Votes

- focus_platform：每显式意图至多一次完整语义级激活尝试，之后只读；新明确输入才有新预算。
- focus_interaction：默认一次，明确暂时失败加新的正向证据可额外一次；纯超时/通知不能重置。
- focus_domain：稳定B后零重试；此前优先只读，不因超时重发，未明确支持额外一次。

## Answer

用户在逐项解释后明确同意：聚焦不自动重试，需要时由新的明确操作再次发起。此为用户裁决，历史专家分歧保留在Votes中。

每次明确激活请求最多一次完整语义级尝试，可以包含必要的应用激活、raise和窗口聚焦步骤，但不能将后续重复尝试伪装成同一次操作。发出后只读确认结果；即使暂时失败后条件恢复，也不自动再发一次。

用户再次按快捷键或发起新的明确聚焦请求，可产生新请求及一次尝试资格；普通重复通知、自动恢复和同一请求重送不视为新的明确操作。尚未发出首次尝试时的资格阻塞不等于已经消耗一次尝试。

确认成功即完成；证据未知保持可诊断且不自动写入的未确认状态；稳定外部竞争满足既定门槛时让权终止。不能将已发出的旧请求因时间、权限或Space变化重新激活。

本票决定后续焦点迁移语义；后台列宽首切片仍要求零额外激活。
